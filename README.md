# Embrasure Homebrew tap

Install the Embrasure CLI on macOS or Linux:

```sh
brew install embrasureai/tap/embrasure
```

Upgrade later with:

```sh
brew upgrade embrasure
```

Source, release checksums, SBOMs, and build attestations are published in the [Embrasure CLI repository](https://github.com/EmbrasureAI/embrasure-cli).
